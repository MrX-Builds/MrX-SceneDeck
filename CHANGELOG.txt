MrX SceneDeck - Changelog
=========================

2.1.2
- Added support for Stash installations served from a URL prefix such as
  /stash/ behind a reverse proxy.
- Scene-route detection, GraphQL requests, generated high-resolution assets,
  sprites and WebVTT requests now resolve from Stash's document base URL.
- Preserved root-hosted Stash behavior and the internal Python connection.

2.1.1
- Rebranded the visible floating-window header and title as MrX SceneDeck.
- Updated the Stash plugin display name and user-facing labels.
- Renamed the plugin folder, manifest, JavaScript, Python backend and internal
  plugin ID to MrXSceneDeck.
- Reads the previous MosaicFloat6x6 grid-size preference once as a migration
  fallback while saving future changes under the new name.

2.1.0
- Added an independent progressive high-resolution upgrade enabled by default.
- Continues showing the immediate sprite grid while the backend generates a
  sharper JPEG from the real scene video, then swaps only after it fully loads.
- Added a Python raw-interface backend that resolves Stash's ffmpeg path and
  stores disposable per-scene/per-grid JPEGs in the plugin directory.
- Captures up to four frames in parallel to reduce first-generation time.
- Added a configurable high-resolution cache limit with oldest-first pruning;
  unset or 0 uses the default limit of 250 sheets.
- Added a Disable high-resolution upgrade setting for sprite-only operation
  with no ffmpeg work or generated cache files.
- High-resolution cell timestamps use the same midpoint sampling positions as
  the generated image, preserving accurate click and Ctrl navigation seeking.
- De-duplicates high-resolution probes and generation requests in the browser.
- Remains independent of Mosaic Poster and does not alter Stash metadata.

2.0.0
- Expanded the original fixed 6x6 floater into selectable 4x4 through 8x8
  grids with automatic opening, keyboard seeking, Ctrl cell navigation,
  scene-navigation preservation and a button-free Multiview-safe interface.
- Replaced the Mosaic Poster overlay dependency with an independent renderer
  built from Stash's existing sprite and WebVTT data.

1.0.0
- Initial floating, resizable and clickable 6x6 Mosaic Poster companion.
